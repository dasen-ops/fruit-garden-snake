# 我们的编程小天地

这里用来把你的点子做成可以玩的小作品。

## 我们怎么一起做

- **你说想法**：想做什么、喜欢什么角色和颜色、想怎么玩，都可以用平常的话说。
- **我来制作**：工具怎么选、程序怎么写、哪里出错，由我来处理。
- **一次聊一件事**：需要你补充时，我一次只问一个重要问题；已经说清楚的就直接做。
- **先玩起来**：先做一个小而完整的版本，再根据你的试玩意见添加或修改。
- **随时改主意**：你可以说“让它跳高一点”“换成蓝色”“加一个怪兽”。想知道为什么时，我再解释。
- **照顾好电脑**：尽量只在这个项目里操作。确实需要改动电脑本身时，先说明影响，并在获得允许后操作。

## 当前状态

第一个作品是 **贪吃蛇 · 水果花园**。双击项目中的 `index.html` 就能打开，不用安装东西，也不用联网。

点击“开始玩”，用方向键、W A S D 或页面上的箭头控制小蛇；也可以在花园上滑动。吃苹果会长大，碰到围墙或身体就结束。点击“暂停”可以休息，“重新开始”可以再玩一次。最好成绩会尽量保存在当前浏览器中。

之后直接说你的点子即可开始，不需要先学习技术术语。

供助手持续遵守的完整约定见 [AGENTS.md](AGENTS.md)，依据《益智编程提示词.pdf》整理。

## 趣味道具

花园会依次出现樱桃、雪花和盾牌，每个停留 12 秒；吃到后 3 秒出现下一个，错过后等待 4 秒。樱桃加 3 分（不额外变长），雪花让移动速度放慢 8 秒，盾牌可挡一次撞墙或撞到身体。护盾触发后自动暂停，先选择安全方向再继续。暂停会冻结道具倒计时；重新开始会清空道具效果。苹果仍然加 1 分并长一格。

## 第一关挑战

第一关要求在 45 秒内吃到 8 颗苹果。4 秒内连续吃到苹果会形成连吃，连吃越多奖励分越高。游戏开始 7 秒后会出现第一颗金苹果；金苹果每隔 1.5 秒换一个位置，停留 8 秒，抓到可得 5 分、长一格并计入任务。完成任务、时间结束或碰撞后，都会显示本局结果。

## 第二关挑战

完成第一关后会直接解锁“石头迷宫”：60 秒内吃到 12 颗苹果。第二关保留连吃、金苹果和三种道具，并增加八块石头与一对传送门。小蛇进入一个传送门会从另一个传送门出来；撞到石头会结束挑战，但护盾可以抵挡一次。重新开始会重玩当前关卡，刷新页面会回到第一关。
